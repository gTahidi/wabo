---
title: Quickstart
---

Install Wabo in your Go module:

```sh
go get github.com/gTahidi/wabo@v0.10.0-beta.1
```

Import `github.com/gTahidi/wabo` and create a client with
`wabo.New(&wabo.ClientConfig{...})`. Supply credentials through environment
variables. Create a messaging client with `client.NewMessagingClient(phoneNumberID)`.

The [README](https://github.com/gTahidi/wabo#usage) contains a complete Go example.
For webhook integration, use the [HTTP backend example](https://github.com/gTahidi/wabo/tree/master/examples/http-backend-integration).
See the [migration guide](/guide/migrating-to-wabo) if upgrading from the previous module.
