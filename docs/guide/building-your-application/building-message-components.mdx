---
title: Building Message Components
---

Message constructors live in `github.com/gTahidi/wabo/pkg/components`.
They return a message and an error; check the error before sending.

```go
message, err := components.NewTextMessage(components.TextMessageConfigs{
    Text: "Hello from Wabo",
})
if err != nil {
    return err
}
```

See the [component reference](/api-reference/pkg/components) for text, media,
contacts, location, templates, reactions and interactive messages. The
[chat bot example](https://github.com/gTahidi/wabo/tree/master/examples/chat-bot)
shows constructors in context.
