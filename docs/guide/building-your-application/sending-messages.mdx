---
title: Sending Messages
---

Create a messaging client for the business phone number ID, then send a component:

```go
messaging := client.NewMessagingClient(phoneNumberID)
response, err := messaging.Message.Send(message, recipientPhoneNumber)
if err != nil {
    return err
}
messageID := response.MessageID()
```

Use `SendContext` to supply a context and deadline. A successful response means
Meta accepted the request; use delivery-status webhook events to track delivery.
Calls return Go values and errors. Applications decide whether an operation can
safely be retried without sending a duplicate message.

See the [message manager reference](/api-reference/manager).
