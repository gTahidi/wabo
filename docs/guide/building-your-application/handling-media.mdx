---
title: Handling Media
---

Use `client.GetMediaManager()` for media operations. The media manager supports
uploading, fetching and deleting media; see its exact method signatures in the
[manager reference](/api-reference/manager).

Incoming image, audio, video, document and sticker events include media metadata.
Use the [event reference](/api-reference/pkg/events) to inspect the available fields.
Document events retain filename and caption when supplied in the webhook.

Never put access tokens or downloaded customer media into public logs.
