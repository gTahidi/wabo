<a name="Transport"></a>
## type [Transport](<https://github.com/gTahidi/wabo/blob/master/internal/testutil/roundtripper.go#L20-L28>)

Transport answers every request with Status and Body and records it.

```go
type Transport struct {
    Status int
    Body   string
    // Handler, when set, replaces the fixed response.
    Handler func(*http.Request) (*http.Response, error)

    mu       sync.Mutex
    Requests []Recorded
}
```
