Package graph holds the typed error returned when the Graph API answers with a non\-2xx status, so callers can decide whether to retry, refresh the access token, or give up.

Meta recommends handling errors by code and error\_data.details; error\_subcode is deprecated from v16.0. See https://developers.facebook.com/docs/whatsapp/cloud-api/support/error-codes

<a name="Error"></a>
## type [Error](<https://github.com/gTahidi/wabo/blob/master/pkg/graph/errors.go#L18-L32>)

Error is a Graph API error response.

```go
type Error struct {
    // HTTPStatus is the HTTP status code of the response.
    HTTPStatus int    `json:"-"`
    Message    string `json:"message"`
    Type       string `json:"type"`
    Code       int    `json:"code"`
    ErrorData  struct {
        MessagingProduct string `json:"messaging_product"`
        Details          string `json:"details"`
    }   `json:"error_data"`
    // ErrorSubcode is deprecated by Meta and not returned from v16.0.
    ErrorSubcode int    `json:"error_subcode"`
    ErrorUserMsg string `json:"error_user_msg"`
    FbtraceID    string `json:"fbtrace_id"`
}
```
